## LinkedIn post

🚀 I just shipped rn-dep-scanner: your React Native project's health check, in one command.

React Native upgrades break builds in surprising ways. This CLI tells you what will break *before* you find out the hard way.

Start here:
👉 npx rn-dep-scanner (no install needed)

What you get:
✅ Compatibility & breaking changes, checked against your actual lockfile
🔐 Security scan of direct and transitive dependencies (OSV.dev)
🏗️ New Architecture and Expo support checks
🩺 `doctor`: JDK, Gradle, Xcode, Node and Hermes, ending in a READY / WARN / BLOCKED verdict
⬆️ `upgrade --to 0.88.0`: a risk score and a step-by-step upgrade path

And 25+ commands beyond that, like:
`why` / `tree` (trace any package), `unused`, `licenses`, `sbom`, `policy`, `diff`, `legacy-apis`, `report`, plus a GitHub Action that comments the verdict on your PRs.

Open source, MIT, works with npm, yarn, pnpm and bun.

📦 npm: https://www.npmjs.com/package/rn-dep-scanner
💻 GitHub: https://github.com/amit13091992/rn-scanner

Give it a spin on your app and tell me what it catches. A ⭐ on GitHub helps a lot!
